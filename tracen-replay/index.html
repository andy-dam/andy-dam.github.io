Tracen Replay

Upload a recording of an Umamusume career and get every turn back as a ledger: stats, skill points, hints, races, each line tied to the frame that proves it.

Open the app Source on GitHub

What it does

  • Reads the game's own screens with OCR, frame by frame, and reconciles what it sees into one account of the career: every stat change, where it came from, and what it cost.
  • Shows the result as a replay: the recording on one side, the turn's ledger on the other, and a click on any line seeks the video to the moment it was read.
  • Says what it is not sure about. Every number carries its evidence and its status, and the viewer can fill in what the footage did not show.

How it is built

  • A Python analyzer (OpenCV, ONNX Runtime, a recognition model trained from scratch for the result cards) behind a Go service and a Vue client.
  • Hosted on Azure: uploads go straight to Blob storage by signed URL, analyses run as queue-triggered container jobs, PostgreSQL holds the records.
  • The same analyzer runs offline on a local recording, which is how every rule in it was checked against real footage before it shipped.

Sign-up is open. An analysis of a full career takes a few hours on the shared worker, and the app shows its progress while it runs.
